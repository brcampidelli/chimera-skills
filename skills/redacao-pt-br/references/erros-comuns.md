# Erros comuns em PT-BR

## Calques e anglicismos evitáveis

| Evite | Prefira |
|---|---|
| endereçar um problema | tratar, resolver |
| performar | ter desempenho, funcionar, render |
| deletar | excluir, apagar |
| aplicar para uma vaga | candidatar-se |
| fazer sentido (para descrever acordo) | concordar; "faz sentido" para lógica está ok |
| no final do dia | no fim das contas |
| eventualmente (= finalmente) | por fim, mais cedo ou mais tarde |
| assumir (= supor) | supor, presumir |
| realizar (= perceber) | perceber, dar-se conta |
| suportar (= dar suporte a) | oferecer suporte, ser compatível com |
| randômico | aleatório |
| mandatório | obrigatório |
| atachar | anexar |

## Falsos cognatos frequentes

actually ≠ atualmente (= na verdade) · pretend ≠ pretender (= fingir) · push ≠ puxar ·
library ≠ livraria (= biblioteca) · application (form) ≠ aplicação (= inscrição, formulário).

## Gerundismo

"Vou estar enviando" → "vou enviar" / "envio". "Estaremos analisando" → "vamos analisar".

## Crase (atalho prático)

- Troque a palavra feminina por uma masculina: se aparecer "ao", há crase. "Fui à feira" → "fui ao
  mercado".
- Nunca antes de verbo, de palavra masculina, de "uma" (salvo locução) ou de pronome de tratamento.
- Horas: "às 14h". Locuções: "à vista", "às vezes", "à medida que".

## Regência que costuma escapar

assistir **a** (ver) · preferir X **a** Y (não "do que") · obedecer **a** · chegar **a** (não "em") ·
implicar (sem "em": "isso implica custo").

## Vírgula

- Não separe sujeito do verbo: "O relatório completo, foi enviado" está errado.
- Vírgula antes de "mas", "porém" (início de oração adversativa).
- Isole expressões explicativas: "O PassaPro, plataforma de estudo, lançou…"

## Hífen e acordo ortográfico

autoescola, antiaéreo, microempresa, semiaberto (prefixo + vogal diferente: junto); micro-ondas,
anti-inflamatório (mesma vogal: hífen); "ideia", "assembleia", "voo", "para" (verbo, sem acento).

## Microcopy de produto

- Botão diz a ação: "Salvar alterações", não "OK".
- Erro diz o que houve e o que fazer: "Não conseguimos salvar. Verifique a conexão e tente de novo."
- Evite culpar o usuário ("Você digitou errado") e evite exclamação em erro.
